# Changelog

All notable changes to @oxog/deps will be documented in this file.

## [1.0.0] - 2025-01-03

### Added
- Initial release of @oxog/deps
- Zero runtime dependencies
- Plugin-based micro-kernel architecture
- Dependency tree visualization
- Circular dependency detection using Tarjan's algorithm
- Unused dependency detection
- Missing dependency detection
- Duplicate version detection
- Size impact analysis
- Update suggestions via npm registry
- Security audit via npm audit
- Monorepo support (pnpm, npm, yarn, Lerna, Turborepo, Nx)
- CLI with all commands
- Multiple output formats (JSON, ASCII tree, Markdown, HTML)
- Caching support
- Watch mode
- MCP server for AI integration
- Full TypeScript support with strict mode
- 100% test coverage target
