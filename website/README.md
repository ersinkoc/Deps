# @oxog/deps Website

## Development

This is the documentation website for @oxog/deps.

The website is built with:
- React 18+
- TypeScript
- Vite
- Tailwind CSS

## Build

```bash
cd website
npm install
npm run build
```

## Deploy

The website is deployed to GitHub Pages via GitHub Actions.

See [deps.oxog.dev](https://deps.oxog.dev) for the live site.
